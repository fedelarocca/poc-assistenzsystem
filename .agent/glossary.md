\# glossary.md — Fachliche und technische Begriffe



\## Case



Ein abgegrenzter Analysefall. Ein Case bündelt Dokumente, Prompts, Ergebnisse und gespeicherte Resultate.



\## Document



Ein einem Case zugeordnetes Ausschreibungsdokument. Das Originaldokument liegt später im Storage, während Metadaten und Referenzen in der Datenbank liegen.



\## Prompt



Ein Analyseauftrag, der an das KI-System übergeben wird. Prompts können angepasst und erneut ausgeführt werden.



\## Result



Eine KI-generierte Ausgabe zu einem Prompt und einem Dokument.



\## SavedResult



Ein ausgewähltes Resultat, das gespeichert und später wieder einem Case zugeordnet aufgerufen werden kann.



\## Analyseperspektiven



Fachliche Kategorien, entlang derer Ausschreibungsunterlagen ausgewertet werden:



\- AGB

\- Risiken

\- Eignungskriterien

\- Anforderungskriterien

\- Verfahrensregeln

\- Termine und Fristen



\## PoC



Proof of Concept. Bewusst begrenztes Artefakt zur Prüfung von Machbarkeit und Erkenntnisgewinn. Kein produktionsreifes System.



\## MVP



Funktionaler Mindestumfang des PoC. Der MVP begrenzt, was umgesetzt und evaluiert wird.



\## Vibe Coding



Promptbasierter, iterativer Entwicklungsmodus, bei dem eine KI zur Generierung, Anpassung und Korrektur von Code eingesetzt wird.



\## Evidence



Nachweismaterial für die wissenschaftliche Auswertung, zum Beispiel Iterationsprotokolle, Prompt-Auszüge, Screenshots, Testläufe, Build-Logs, Commit-Verweise und Bewertungsmatrix.
